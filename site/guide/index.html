STATUSORBIT 使用指南

第一次使用，从这里开始。

这份指南会带你看懂每个页面是做什么的，也会告诉你结束进程和清理文件时需要注意什么。

约 8 分钟读完
01

开始使用

第一次打开 StatusOrbit，可以按这三个步骤熟悉界面。

先下载适合当前系统的安装包前往 GitHub Releases 下载。macOS 首个版本尚未经过 Apple 公证；如果第一次打开被阻止，请在“系统设置 → 隐私与安全性”中确认打开。Windows 与 Linux 安装包目前属于早期预览版本。
  1. 1
    等几秒，让数据准备好

    刚启动时，网络和磁盘速率可能显示“预热”。等到下一次刷新就会出现正常数据。

  2. 2
    先用简单模式

    在窗口右上角选择“简单模式”，先看电脑是否正常、哪个应用最忙。

  3. 3
    需要时再看详细信息

    需要定位具体进程、连接或命令行时，再在右上角切换到“专业模式”。

02

概览

概览页顶部的“智能诊断”会结合 CPU、内存、磁盘、网络和最近一段时间的变化，先说明电脑当前是否正常，再给出对应证据。一次短暂波动不会被说成故障。

◎先看状态

先确认整体是否正常，再决定要不要继续查看。

⌁看看最近几分钟

趋势图能帮你分清短暂变忙和持续卡顿。

↗点进去找原因

从提示直接进入相关页面，看看是哪个应用或资源最忙。

03

应用

简单模式会把同一个应用的相关进程合在一起，方便你找到最占资源的应用。专业模式则提供进程树、搜索、排序和完整详情。

  • 单击应用或进程，可以查看它的位置、启动命令、上级进程和最近五分钟的占用。
  • 优先使用“请求结束”，让应用有机会保存状态；只在必要时强制结束。
  • 为了避免结束错进程，StatusOrbit 会在执行前再次确认目标。进程已经退出或发生变化时，操作会自动停止。
04

存储

存储页显示每个磁盘还剩多少空间、最近的读写变化，以及哪些应用正在频繁读写。磁盘空间不足时，可以从这里直接进入“清理”页面。

macOS 系统卷只显示一次属于同一个 APFS 系统卷组的 / 与 Data 卷会合并显示，不会重复计算；外置磁盘不受影响。
05

清理

清理页扫描文件和文件夹，再用扇形图显示空间被什么占用了。扫描会一直进行到完成，除非你主动停止。

单击查看里面拖进清理篮检查后再删除
只删除你认识、并且确定不再需要的内容不确定的内容先保留。可以重新生成的缓存适合作为起点，但缓存也不等于全部都能安全删除。
  1. 1
    等待扫描完成

    页面会持续显示正在扫描的位置、已经检查的项目和找到的空间。你也可以随时停止。

  2. 2
    查看大文件夹

    扇区越大，占用的空间越多。单击文件夹进入，单击中间区域返回上一级。

  3. 3
    放进清理篮

    按住扇区并拖到左下角。放进清理篮不会立即删除文件。

  4. 4
    检查后永久删除

    确认名称、位置和大小都正确，再继续。文件不会进入废纸篓，删除后无法撤销。

完整扫描结果会在本机保留 7 天。再次打开清理页时可以继续查看；进入某个文件夹时，StatusOrbit 会核对当前这一层并更新扇形图。如果其他位置发生了较多变化，请选择“重新扫描”。

永久删除不会进入废纸篓删除后无法通过 StatusOrbit 恢复。确认名称、位置和大小都正确后再继续。
06

网络

网络页显示当前上传和下载速度、本次启动后的累计流量，以及正在活动的 TCP / UDP 连接。系统不一定允许普通应用读取每条连接属于哪个进程，所以没有显示应用名并不代表连接有问题。

07

启动项

启动项页面告诉你哪些应用会随电脑启动。支持的第三方项目可以关闭，也可以稍后恢复；系统项目只供查看。StatusOrbit 不会直接删除它们的配置文件。

08

历史

  • 历史页按时间保存 CPU、内存、磁盘和网络的整体变化，让你回看电脑什么时候开始变忙、什么时候恢复正常。
  • 记录可以保留 1、7 或 30 天。你也可以关闭历史记录，或者随时清空。
  • 只有问题持续一段时间时才会提醒；同一问题不会反复弹出。CPU、内存和磁盘提醒可以分别关闭。
09

设置

设置页可以更改语言、系统采样速度、活动连接刷新速度、颜色提示、默认的应用列表样式，以及历史记录和桌面提醒。更短的刷新间隔响应更快，也会增加少量系统开销。

10

安全与隐私

结束进程应用会在最后一步确认，并再次检查目标。系统关键进程和 StatusOrbit 本身不能被误关。
永久删除只处理你个人文件夹内的普通文件和文件夹。主目录、废纸篓本身、链接和其他磁盘不会被删除。
系统权限StatusOrbit 不会自动申请更高权限。看不到某些信息时，页面会直接说明。
你的数据监控、文件、进程、历史和连接信息只保存在这台电脑上，不会上传或同步。扫描只读取名称、大小、位置等文件信息，不读取文件内容。
11

常见问题

刚启动时为什么没有网络或磁盘速度？

应用需要先后读取两次数据才能算出速度。等到下一次刷新就会显示。

为什么扫描要等很久？

扫描时间主要取决于文件数量和磁盘速度。大量小文件通常比少量大文件更慢。页面会持续更新进度，你也可以主动停止。

为什么大小和 Finder / Explorer 显示的不一样？

StatusOrbit 显示文件实际占用的磁盘空间。压缩文件、稀疏文件和硬链接等情况，可能会让这个数字与文件标称大小不同。

还是遇到了问题？

可以在 GitHub 提交问题。写清楚你的操作系统、刚才做了什么，以及看到的错误信息，会更容易定位。安全问题请使用私密漏洞报告。
