STATUSORBIT 使用指南

第一次使用，从这里开始。

这份指南会带你看懂每个页面是做什么的，也会告诉你结束进程和清理文件时需要注意什么。

随产品持续更新约 8 分钟读完
01

快速开始

StatusOrbit 还没有正式安装包，目前需要从源码运行。已经熟悉开发工具的用户可以按下面的步骤开始；如果你不熟悉这些工具，建议先关注项目进展，等待安装包发布。

从源码运行需要Node.js 22、pnpm 10.33、Rust 1.95，以及当前系统需要的 Tauri 2 依赖。
git clone https://github.com/JimmyDaddy/StatusOrbit.git
cd StatusOrbit
corepack enable
pnpm install
pnpm dev

需要生成原生应用时，运行：

pnpm tauri build

第一次打开

  1. 1
    等几秒，让数据准备好

    刚启动时，网络和磁盘速率可能显示“预热”。等到下一次刷新就会出现正常数据。

  2. 2
    先用简单模式

    它会先告诉你电脑是否正常、哪个应用最忙，适合日常查看。

  3. 3
    想看更多，再切换专业模式

    PID、连接协议、命令行和完整趋势都在专业模式里。

02

概览：先看电脑哪里忙

概览页把 CPU、内存、磁盘和网络放在一起。StatusOrbit 会结合最近一段时间的变化判断是否需要留意，不会因为一次短暂波动就说电脑出了问题。

◎先看状态

先确认整体是否正常，再决定要不要继续查看。

⌁看看最近几分钟

趋势图能帮你分清短暂变忙和持续卡顿。

↗点进去找原因

从提示直接进入相关页面，看看是哪个应用或资源最忙。

03

应用与进程

简单模式会把同一个应用的相关进程合在一起，方便你找到最占资源的应用。专业模式则提供进程树、搜索、排序和完整详情。

  • 单击应用或进程，可以查看它的位置、启动命令、上级进程和最近五分钟的占用。
  • 优先使用“请求结束”，让应用有机会保存状态；只在必要时强制结束。
  • 为了避免结束错进程，StatusOrbit 会在执行前再次确认目标。进程已经退出或发生变化时，操作会自动停止。
04

存储与安全清理

存储页告诉你还剩多少空间、哪些应用正在频繁读写。清理页则扫描文件和文件夹，用扇形图显示空间都被什么占用了。扫描会一直进行到完成，除非你主动停止。

单击查看里面拖进清理篮检查后再删除
  1. 1
    等待扫描完成

    页面会持续显示正在扫描的位置、已经检查的项目和找到的空间。你也可以随时停止。

  2. 2
    查看大文件夹

    扇区越大，占用的空间越多。单击文件夹进入，单击中间区域返回上一级。

  3. 3
    放进清理篮

    按住扇区并拖到左下角。放进清理篮不会立即删除文件。

  4. 4
    检查后永久删除

    确认名称、位置和大小都正确，再继续。文件不会进入废纸篓，删除后无法撤销。

永久删除不会进入废纸篓建议先清理可以重新生成的缓存。下载内容、项目文件、设置和个人资料不确定时不要删除。
05

网络与启动项

活动连接

网络页显示当前上传和下载速度、本次启动后的累计流量，以及正在活动的 TCP / UDP 连接。系统不一定允许普通应用读取每条连接属于哪个进程，所以没有显示应用名并不代表连接有问题。

启动项

启动项页面告诉你哪些应用会随电脑启动。支持的第三方项目可以关闭，也可以稍后恢复；系统项目只供查看。StatusOrbit 不会直接删除它们的配置文件。

06

历史、提醒与设置

  • 历史页按时间保存 CPU、内存、磁盘和网络的整体变化，让你回看电脑什么时候开始变忙、什么时候恢复正常。
  • 记录可以保留 1、7 或 30 天。你也可以关闭历史记录，或者随时清空。
  • 只有问题持续一段时间时才会提醒；同一问题不会反复弹出。CPU、内存和磁盘提醒可以分别关闭。
  • 设置页还可以更改语言、刷新速度、颜色提示和默认的进程列表样式。
07

操作前要知道的事

结束进程应用会在最后一步确认，并再次检查目标。系统关键进程和 StatusOrbit 本身不能被误关。
永久删除只处理你个人文件夹内的普通文件和文件夹。主目录、废纸篓本身、链接和其他磁盘不会被删除。
系统权限StatusOrbit 不会自动申请更高权限。看不到某些信息时，页面会直接说明。
你的数据监控、文件、进程、历史和连接信息默认只保存在这台电脑上。
08

常见问题

刚启动时为什么没有网络或磁盘速度？

应用需要先后读取两次数据才能算出速度。等到下一次刷新就会显示。

为什么扫描要等很久？

扫描时间主要取决于文件和文件夹的数量。开发缓存、小文件很多或部分文件夹无法读取时，会花更长时间。页面会持续更新进度，你也可以主动停止。

为什么大小和 Finder / Explorer 显示的不一样？

StatusOrbit 显示文件实际占用的磁盘空间。压缩文件、稀疏文件和硬链接等情况，可能会让这个数字与文件标称大小不同。

开发时提示端口 1420 被占用怎么办？

通常是旧的 Vite/Tauri 开发进程仍在运行。结束旧进程后再启动，避免同时运行多个 pnpm dev 实例。

还是遇到了问题？

可以在 GitHub 提交问题。写清楚你的操作系统、刚才做了什么，以及看到的错误信息，会更容易定位。安全问题请使用私密漏洞报告。
