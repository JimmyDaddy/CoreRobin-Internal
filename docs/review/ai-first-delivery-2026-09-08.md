四种协议、原生会话运行时、设置、只读分析入口和 Robin 聊天窗口已实现。实现过程的独立审查发现并修复了凭据版本冲突、跨窗口草稿覆盖、旧来源复用、清除期间旧历史回写，以及窗口交接失败等问题。下表记录已关闭项；平台与真实服务的未验证部分单列，不把合成测试当作发布验收。

## 实现范围

| 模块 | 本批行为 |
| --- | --- |
| 连接 | Ollama NDJSON、OpenAI Chat Completions、OpenAI Responses、Anthropic Messages；各自请求和流解析；模型发现与手填；合成模型测试 |
| 设置 | 多连接、默认模型、三个场景覆盖；已有会话保留所选模型；只有空白且尚未选模型的会话在首次配置后绑定默认模型；服务失效不自动换模型 |
| 凭据与网络 | 系统凭据库、显式临时凭据、独立代理凭据；本机/公网/内网策略、HTTPS、DNS 地址校验与固定、显式代理；禁止环境代理、跳转与自动重试 |
| 对话 | 默认保存在原生 SQLite；分页历史、重命名、单个/全部删除、临时会话、草稿冲突处理；崩溃恢复标中断且不重发 |
| 请求控制 | 先持久保存再发送、冻结预览、范围授权、版本/epoch 校验、提交去重、单个并发生成、超时、取消、输出与存储预算、每日请求数上限 |
| 只读上下文 | 当前采样摘要、已有健康状态、资源历史、既有网络检查摘要、所选历史事件；原生白名单投影，不带应用名、文件路径、IP 或凭据；缺失与过期数据明确说明 |
| 入口 | 日常/专业模式共享 AI 设置；完整助手页、当前状态/网络/历史场景面板；独立 `robin-chat.html` 与最小 ACL；小鸟点击和拖动区分 |
| 窗口接续 | 原生保存待处理导航；同会话、草稿、消息页与可见消息锚点接续；主窗确认可见并加载成功后再隐藏聊天；隐藏不取消已授权生成，退出取消生成；macOS workspace、Windows WTS/电源与 Linux logind 会话信号隐藏正文 |
| 隐私清除 | 清除来源先使准备对象与派生上下文失效；多存储清除期间阻止准备/发送；可保留并标记对话副本，或同时删除相关会话；失败显示回执且可重试 |

首批输出支持安全纯文本和经过本机校验的结构化结果。Schema 模式须用户单独触发合成测试，能力记录绑定连接版本、协议、模型、流式参数和输出配置并记录时间；四种协议分别发送原生 Schema 字段。未验证或测试失败时使用文本，不自动重发真实请求。合法结果只关联本机证据和固定页面导航；未知证据、额外测量字段、非法目标或未完成 JSON 不生成结果卡。没有原始 HTML、远程图片、任意链接导航或可执行模型工具；完整应用归因仍取决于实际证据覆盖。

## 已修复问题

| 级别 | 问题与影响 | 修复与验证 |
| --- | --- | --- |
| P2 | 换模型复用了旧会话，可能转发先前服务的历史 | 有消息时原生新建会话，保留旧历史和草稿；新会话不携带旧消息，重新预览与授权 |
| P2 | 自由文本含疑似路径、地址或凭据时缺少本机提醒 | 对本轮及选中历史执行有界启发式检查，只返回类别；记住授权也必须重新确认，不宣称完整脱敏 |
| P2 | 处理位置变化未纳入授权范围 | 已知云模型单独披露；处理位置类别进入授权摘要，发现新的云处理信息作废准备对象与旧授权 |
| P2 | 预览冻结后 Schema 能力变为失败或过期，发送仍可能使用旧能力 | 写入消息和建立运行前重新核验当前能力；失败和过期回归均断言拒绝旧预览且不产生消息或运行，独立复核已关闭 |
| P2 | DeepSeek Responses 的推理内容分段被误判为不支持，导致正常回复失败 | 真实事件类型核对后，仅丢弃已知 `reasoning_text` 分段；33 种分片长度与非流式回归确认推理不进入可见内容，未知类型和仅有推理的回复仍不成功；修复后真实流式与非流式通过 |
| P2 | OS 凭据操作占用运行时锁，故障可能拖住取消和界面 | 凭据操作移到阻塞任务与锁外，完成后校验版本；迟到结果不能覆盖新配置 |
| P2 | 设置凭据后连接 revision 未同步，下一次保存错误地报冲突 | 成功、失败和删除路径均刷新 revision；失败保留输入以便重试 |
| P2 | 脏草稿随远端刷新被自动换基，可能覆盖另一窗口输入 | 首次编辑版本 CAS；明确选择加载远端或覆盖，失败和卸载不静默丢草稿 |
| P2 | 当前会话异步错误未显示、无关会话可能显示错误 | 按 sessionId 展示运行错误；失败/中断消息不再误标为“源数据已清除” |
| P2 | 设置数值边界与 native 不一致 | 超时 10–300 秒、输出 32–8192、存储 8–2048 MiB，含最小输出提交测试 |
| P2 | 删除来源后旧预览、后续多轮转述或迟到流可能继续复用 | 会话级来源追踪、epoch、准备对象失效、活动请求取消与事件版本校验；物理清理 SQLite 残页 |
| P2 | 多存储清除存在间隙；在途 writer 和延迟 hydration 可恢复旧历史 | 原生清除 token 覆盖整个操作、所有删除 settle 后结束；history generation/CAS 拒绝旧快照；前端等待 hydration/migration/在途保存 |
| P2 | AI 数据库不可用时原隐私清理不可用，或总清理错误报告成功 | 来源清理先持久化失效标记，恢复 AI 前重放；删除 AI 自身失败如实返回，不假报完成 |
| P2 | 所选旧事件可能被“最新几条”截断或时间窗口超出事件范围 | 优先保留所选事件及关联恢复记录，固定场景时间范围，不生成原因推断 |
| P2 | 主窗口 reveal 失败时错误 ACK 会丢失唯一可用聊天窗口 | 保留 pending，show/unminimize/focus 错误返回；ACK 仅在可见且未最小化时完成 |

窗口交接、早期 UI 六项问题和跨平台事件 helper 已由独立审查者复核。后续完整性补丁另做了定向独立审查，发现并关闭上述 Schema 能力失效问题；这些审查范围内未发现剩余 P1/P2。随后重新运行全量前端、原生与浏览器检查，并用最新隔离原生构建检查结构化结果和接续。原生 OS 窗口失败分支为源码复核，未注入操作系统故障。

## 验证记录

验证在本机工作区进行；日志和截图位于被忽略的 `.local-dev/ai-validation/`。

- 全量前端：150 个文件、801 条通过；TypeScript、ESLint 无错误；10 个语言目录校验及类型检查通过。
- macOS 原生：476 条通过、5 条忽略（一个既有用例、一个需显式运行的 OS 凭据 smoke、三个需明确授权的真实服务 smoke）；包括协议、上下文、清除标记恢复、并发清除、history CAS、会话生命周期、Schema 能力失效、推理内容隔离、回调停用和几何边界。`cargo fmt --check` 与 `cargo clippy --all-targets -- -D warnings` 通过。
- 浏览器界面：主助手、400×540 聊天及 1180×720/960×640 长会话布局四个 smoke 通过，合成 IPC fixture 覆盖预览、发送、失败、历史、输入法 composition 和接续参数。使用已安装 Chrome：`CORE_ROBIN_PLAYWRIGHT_CHANNEL=chrome pnpm exec playwright test tests/visual/ai.visual.spec.ts`。
- 隔离原生应用：独立 bundle identifier、独立应用数据目录；通过真实 IPC 访问 `127.0.0.1` 合成 Ollama 服务，无云端密钥或外部设备数据披露。无正常终止标记的流被判失败，修正服务响应后生成测试成功；主窗口和小窗均完成流式对话，主窗隐藏时仍可发送并保存；取消保留部分文本及状态，草稿接续到同一主窗会话。
- 最新隔离构建补验：用户可单独触发 Schema 测试，成功状态及时间可见；路径/凭据合成文本触发本机提醒，取消后服务未收到请求。完整结构化回复在主窗和 400×540 小窗均显示结果卡，`E1` 数值和单位与冻结预览一致，未把合成回复当作真实推理。小窗返回主窗后同一会话、结果及中文草稿保留，服务日志无重复请求；布局未遮住输入区。可见消息锚点在不同窗口高度下允许滚动范围钳制，分页与锚点边界由自动化测试补充覆盖。
- macOS 系统凭据库：显式运行合成凭据写入、读回、删除及删除后不可读测试通过；使用唯一临时标识且已清除，不读取用户模型密钥。
- 平台 helper：Windows MSVC 与 Linux x86_64 隔离 harness `check --tests`、Clippy 通过；Windows 2 条分类测试、Linux 13 条分类/取消/重试测试通过。停用后拒绝新回调，已进入的同步回调可完成；退出等待有界。

## 验证缺口与发布边界

1. 已完成用户授权的 DeepSeek 与 Ollama 合成 live smoke；OpenAI、Anthropic 官方账号和百炼尚未验证。真实 Ollama 冷启动/资源失败、持续推理负载、限流与账号差异仍缺证据。
2. Windows/Linux 全应用实机焦点、输入法、系统凭据库、锁屏和多显示器/工作空间仍需设备矩阵验证。平台 helper 的编译/单元测试不等同于原生 UI 验收。
3. Linux 锁屏依赖桌面向 logind/elogind 报告当前会话状态；没有可靠会话信号的桌面不得宣称已完成锁屏保护验收。
4. 来源清除过程中 WebView 重载会保守阻止新的 AI 发送。若操作无法完成，重启应用后重试来源清除；不会自动恢复旧准备对象或重发模型请求。
5. 尚未做真实本地推理期间的采样延迟、能耗和内存长期基准，也未注入全部磁盘/OS 凭据故障。
6. Gemini 原生协议、模型只读工具与写操作未实现。纯文本回答仍可能出错，界面不把它当成已执行操作或可验证诊断结论。
