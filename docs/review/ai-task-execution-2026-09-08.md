# Robin 任务执行验收

2026-09-08，CoreRobin-Internal。范围是用户要求补齐的“执行任务而非只给建议”，沿用此前消融后的聊天流程。未提交、未推送、未调整版本、未修改公开分发仓库。

## 实现与边界

- Rust 接通七项固定工具：设备状态、进程占用、已有历史、网络检查、常用目录扫描、请求关闭/强制结束进程、请求移到废纸篓。模型工具调用经参数校验后执行原生能力，再把实际结果交回同一模型继续回答。
- 主窗和 Robin 小窗共享执行步骤、结果、取消和原生确认。400×540 小窗等待确认时收起下一轮上下文控件，使当前目标、风险和按钮同时可见；草稿仍可编辑。全局任务中心可打开、取消同一任务。
- 普通聊天仍按 Enter 一步发送、默认包含设备上下文；取消上下文则本轮不提供工具。预览说明后续可能读取进程名称及文件占用元数据，不声称冻结尚未发生的工具结果。
- 目标引用由本机生成并绑定任务。模型不能提交 PID、任意路径、Shell、永久删除或文件正文读取。关闭与废纸篓动作必须逐项确认，复用原生租约、进程出生身份和清理目标校验；拒绝一个修改动作后，本任务不再申请其他修改。
- 最多六次模型请求、八个工具调用；相同工具和参数在本任务复用回执，不重复原生操作。每个结果不超过 8 KiB，工具元数据有独立预算；记录分页计算执行证据大小。新检查可重新发起任务，不自动重试失败请求。
- 取消、来源清除、设置失效、关闭 AI、退出和重启均不自动接着执行。进行中的 OS 操作不承诺回滚；进程关闭回执不等于进程已退出，移到废纸篓也不保证立即释放空间。扫描不会替换或取消用户已有任务。
- 四协议的推理/签名续接数据只在当前请求内存中使用，不显示、不写 SQLite、不进入普通会话历史或日志。文件完整路径仅保留在本机确认记录，工具结果使用名称、占用和不透明引用；原生错误的完整路径不转发模型。

## 原生实测追加

- 独立测试包使用本机 `llama3.2:latest`，在临时对话中完成设备状态与进程检查，模型引用了实际进程 CPU 数值，步骤和原生 JSON 均可见。
- 网络工具完成检查，实际回执是本地链路通过、DNS 失败；历史工具读取已有样本并说明覆盖范围。验收不把探测失败写成联网成功，也未自动开启记录。
- 从原生 Robin 小窗发起常用目录扫描，扫描任务和未发送草稿一起接续到主窗口。草稿未丢失、未额外发送；扫描最终完成并返回真实文件占用元数据。未移动或删除文件。
- 进程确认初测暴露小模型跳过查询、直接将名称当目标引用；原生层拒绝，辅助程序按自身期限退出。为减少错误调用，修改工具现仅在本轮检查返回合格目标后提供；新增 HTTP 回归验证工具定义按原生目标出现。修正后的真实模型确认流程待复测。

## 保留的缺口

Windows/Linux 原生应用、OS 输入法/锁屏/多屏、冷启动和长期能耗尚未完成实机验收；现有跨平台控制器的可用性限制仍适用。当前工具没有后台定时运行、任意设置修改、跨任务目标复用、任意文件分析或通用工作流能力。不具备工具调用能力的模型可能只回答文字或由服务端拒绝工具请求，应用不会解析其普通回答来模拟执行。

## 应用能力卡片后续阶段

本报告前文保留任务执行阶段的历史结果。后续已完成 19 项业务能力、36 项工具表单、直接卡片操作和共享业务结果；当前自动化为前端 839 项、原生 508 项（另有 7 项忽略）、浏览器 12 项通过。最后的 JSON 输入属性调整另复跑相关 28 项前端测试、类型构建与 ESLint；原生新增分片参数回归后重新通过全量测试及 Clippy。

最终 macOS 测试包已完成非空 JSON 的真实模型计算、共享表单与原工具箱回写、设备卡片直接刷新及草稿保留。隐私操作表单的嵌套清除确认已打开并取消，没有清除数据。原有五条会话及八条运行记录的内容哈希保持一致，测试临时会话已清理。

保留了小模型提交多余参数、无效 JSON 和误读设备单位的失败证据；应用显示原生回执，不把模型文字计作实际执行。具体操作边界、包体增量和平台验证限制见 [接入清单](../application-capability-inventory.md) 与 [应用能力设计](../application-capabilities-design.md)。此前的锁屏阻断已解除，当前没有等待解锁的验收项；Windows/Linux 和全部系统副作用仍未实机覆盖。
