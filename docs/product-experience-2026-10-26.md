# 2026-10-26 用户体验与性能优化交付记录

本轮在此前磁盘扫描可靠性改进的基础上，落实真实桌面体验报告中的 A1–A9。
修改属于 Internal 源码；没有更新版本、发布安装包或替换本机已安装应用。

## 逐项结果

| 项目 | 用户现在得到的行为 | 验证与边界 |
| --- | --- | --- |
| A1 后台扫描缓存开销 | 未变化的索引代际不重复加载地图；并发恢复共用读取；路径锚点检查使用路径索引，读取有 5 秒预算 | 原生索引测试覆盖查询计划、代际恢复与读取预算；前端测试覆盖连续 12 次恢复通知只加载一次。正式索引的只读探测曾从 250 ms 未完成变为 0.27 ms 返回，但没有重测新安装包的整机能耗 |
| A2 应用身份与关联 | 嵌套辅助进程归到外层应用；共享 WebKit 无法确认宿主时独立显示；启动项只使用规范身份或精确名称关联；未读取的数据不再显示为 0 | 包含外层 macOS bundle、Codex 辅助进程、独立 WebKit 和启动项名称碰撞测试。没有把未知宿主猜成某个应用，也没有放宽进程操作权限 |
| A3 应用列表浏览 | 默认聚焦用户应用，系统项可显示、所有项可搜索；每页只渲染 24 行；实时数值更新时保持浏览顺序，可主动重新排序 | 500 项夹具验证渲染行数、更新后顺序和翻页。这里采用分页，未声称使用虚拟滚动或测得特定 CPU 降幅 |
| A4 跨天持续问题 | 昨天开始且仍未结束的事件继续计入回顾，避免误报“全部恢复” | 跨午夜持续事件回归测试 |
| A5 快速清理可控性 | 废纸篓默认不选；类别可展开来源、大小并保留特定位置；预计清理量和确认页反映保留项；入口说明“无需整盘扫描” | 只读分析每类最多检查 250,000 个项目，展示至多 128 个较大来源，并说明不完整预览。排除项只减少删除范围；保留嵌套文件会保留其整个来源目录。临时夹具验证保留、删除其他项、拒绝父路径穿越、取消和不跟随链接。本机真实文件未执行删除 |
| A6 休眠解释 | 已知系统维护不会被不完整应用信息覆盖；可查看原因、休眠类型、电源状态；计划中的任务可在本次运行中免于提醒并撤销 | 标记绑定进程出生身份及当前断言，任务结束或进程重启后失效；原始传感器事实继续保留，不改变系统电源设置。浏览器完成标记、提醒消失和撤销闭环 |
| A7 首页首屏 | 当前首要问题、影响说明和对应处理入口进入主区域；没有问题时展示整体状态；Robin 保持紧凑 | 1280×720 浏览器预览验证主要动作不滚动可见，一次进入相关证据；四种桌面宽度保留视觉回归 |
| A8 工具箱表达 | 优先展示可用工具、收藏和本次最近使用；受限工具仍保留在分类中；限制使用界面语言，不直接输出 provider/helper 原文 | 十种语言补充说明。页面测试验证受限工具仍可打开、不可用工具不执行；浏览器验证最近使用排序 |
| A9 实时进程详情 | 运行时间、状态和用户信息优先使用现有实时行，稳定详情继续复用缓存 | 不增加高频详情请求；继续使用原有进程身份校验 |

- 前端：166 个测试文件、876 个测试通过；lint、类型检查和国际化检查通过。
