# StatusOrbit 使用指南

StatusOrbit 是一款本地优先的桌面资源管理器。它把 CPU、内存、磁盘、网络和进程信息整理成容易理解的状态、原因和建议，同时保留适合进一步排查的专业数据。

> 当前已在 macOS 完成真实窗口和原生构建验证。Linux 与 Windows 由 CI 持续编译，但仍需要补充目标系统上的运行时验证。

## 安装与启动

StatusOrbit 目前处于开发阶段，尚未提供正式安装包。可以从源码构建：

1. 安装 Node.js 22、pnpm 10.33、Rust 1.95 和当前平台需要的 [Tauri 2 系统依赖](https://v2.tauri.app/start/prerequisites/)。
2. 克隆仓库并进入目录。
3. 执行：

```bash
corepack enable
pnpm install
pnpm dev
```

构建原生应用：

```bash
pnpm tauri build
```

## 第一次使用

1. 打开“概览”，等待第一轮采样完成。网络和磁盘速率需要前后两帧数据，刚启动时显示“预热”属于正常情况。
2. 普通用户建议保留“简单模式”。它优先显示电脑是否正常、可能原因和下一步建议。
3. 需要查看 PID、协议、命令行或完整趋势时切换到“专业模式”。两种模式共享同一份数据，切换不会清空历史。
4. 在“设置”中选择语言、采样间隔、告警阈值、历史保留时间和桌面提醒类别。

## 主要页面

### 概览与智能诊断

- CPU、内存、磁盘、网络等实时数据集中显示在概览页。
- 智能诊断会结合持续时间判断问题，不会把一次短暂尖峰直接当作故障。
- “查看证据”会带你进入对应页面；诊断本身不会自动结束进程或删除文件。

### 应用与进程

- 简单模式按应用归并多个辅助进程，适合回答“哪个应用让电脑变慢”。
- 专业模式支持平铺、进程树、搜索、排序和虚拟滚动。
- 选中进程可以查看路径、命令、父进程以及最近 5 分钟的 CPU、内存和磁盘 I/O 趋势。
- 请求结束或强制结束前，StatusOrbit 会创建一次性短期确认，并复核进程身份。系统关键进程和 StatusOrbit 自身默认受保护。

### 存储与空间清理

- “存储”展示磁盘容量、剩余空间、最近读写趋势和高 I/O 进程。
- 从存储页进入“清理”，开始完整空间扫描。扫描会显示当前路径、已检查项目、已发现空间和耗时，可以随时停止。
- 扇形图面积代表实际磁盘占用。点击扇区进入目录，点击中心返回上一级。
- 按住文件或目录扇区，将其拖入左下角清理篮。放入清理篮不会立刻删除。
- 点击“检查并永久删除”后，再次核对名称、路径、大小和扫描后的变化。

#### 永久删除的安全边界

- 删除不会进入系统废纸篓，确认后无法通过 StatusOrbit 恢复。
- StatusOrbit 只允许处理当前用户主目录内的普通文件和文件夹。
- 主目录、废纸篓根目录、符号链接、特殊文件和跨磁盘挂载点会被拒绝。
- 删除确认是短期且单次使用的；目标在确认后变化时会停止操作。
- 成功项会立即从空间图和缓存中移除；失败项会留在清理篮中并标红。

建议先处理可重新生成的缓存。下载、配置、工程文件和个人资料必须确认来源后再删除。

### 网络

- 查看上下行速率、本次启动累计流量、网络接口和 TCP / UDP 活动连接。
- 可以按协议和状态筛选连接。
- 连接所属进程受系统权限限制；没有归属信息不代表连接异常。

### 启动项

- 展示常见用户级自启动项、来源和风险提示。
- 可恢复的第三方用户启动项可以停用和恢复；系统项或平台不支持的来源保持只读。
- 修改前会再次核对文件身份，不会直接删除启动项文件。

### 历史与提醒

- 历史页保存 CPU、内存、磁盘和网络的本机聚合快照，并记录持续告警与恢复事件。
- 可以选择保留 1、7 或 30 天，也可以完全停用或清除历史。
- 默认不记录应用名、命令、路径、文件名或连接地址。所有历史只保存在当前设备。

## 状态栏面板

关闭主窗口不会影响状态栏入口。状态栏面板用于快速查看 CPU、内存、磁盘和网络状态，并可重新打开主窗口。实时采样是否继续取决于应用是否仍在运行，而不是窗口是否可见。

## 常见问题

### 刚启动时为什么没有网络或磁盘速率？

速率需要比较两次累计计数。等待下一个采样周期后会出现数据。

### 清理扫描为什么需要较长时间？

StatusOrbit 会完整遍历选定范围，不设置静默时间或数量上限。大量开发缓存、小文件或权限受限目录会延长扫描时间。扫描在后台执行，可以主动停止。

### 为什么扫描结果和 Finder 显示的大小不同？

StatusOrbit 优先显示实际占用空间；稀疏文件、硬链接、文件系统压缩和 APFS 行为都可能让它与文件逻辑大小不同。

### 为什么某些连接没有进程名？

操作系统可能限制普通用户读取连接归属。StatusOrbit 不会为了补全这些数据自动提权。

### 开发时提示端口 1420 已被占用怎么办？

通常是之前的 Vite/Tauri 开发进程仍在运行。先找到并结束旧进程，再重新执行 `pnpm dev`，不要同时启动多个开发实例。

## 隐私与问题反馈

StatusOrbit 默认不上传遥测、进程、文件、历史或连接数据。发现安全问题时请使用 GitHub 的私密漏洞报告功能；普通问题可以在仓库 Issues 中反馈，并附上操作系统、复现步骤和相关错误信息。
