# StatusOrbit 使用指南

StatusOrbit 把 CPU、内存、磁盘、网络和正在运行的应用放在一个清晰的桌面界面里。电脑变慢、磁盘快满或网络突然繁忙时，你可以用它更快找到原因。

## 第一次打开

1. 先等几秒，让第一轮数据准备好。刚启动时，网络和磁盘速度可能显示“预热”；下一次刷新后就会出现。
2. 在窗口右上角选择“简单模式”，先看电脑是否正常，以及哪个应用最忙。
3. 需要定位具体进程、连接或命令行时，再在右上角切换到“专业模式”。
4. 在“设置”中可以更改语言、刷新速度、颜色提示、历史保留时间和桌面提醒。

## 主要页面

### 概览

- CPU、内存、磁盘和网络状态会集中显示在概览页。
- StatusOrbit 会参考最近一段时间的变化，不会因为一次短暂波动就说电脑出了问题。
- 看到需要留意的提示时，可以直接进入相关页面，看看是哪个应用或资源最忙。

### 应用

- 简单模式会把同一个应用的相关进程合在一起，方便你找到最占资源的应用。
- 专业模式提供进程树、搜索、排序、路径、启动命令和最近五分钟的资源变化。
- 结束进程时，优先选择“请求结束”，让应用有机会保存内容。只有应用完全没有响应时，再考虑强制结束。
- 为了避免结束错进程，StatusOrbit 会在执行前再次检查目标。如果进程已经退出或发生变化，操作会停止。
- 系统关键进程和 StatusOrbit 本身不能被误关。

### 存储

- 查看每个磁盘还剩多少空间、最近的读写变化，以及哪些应用正在频繁读写。
- 在 macOS 上，属于同一个系统卷的 `/` 和 Data 卷会合并显示，不会重复计算。
- 磁盘空间不足时，可以从这里直接进入“清理”页面。

### 清理

清理页面会扫描文件和文件夹，并用扇形图显示空间都被什么占用了。

> 只删除你认识、并且确定不再需要的内容。不确定的内容先保留。可以重新生成的缓存适合作为起点，但缓存也不等于全部都能安全删除。

1. **等待扫描完成**：页面会持续显示正在扫描的位置、已经检查的项目和找到的空间。扫描会一直进行到完成，除非你主动停止。
2. **查看大文件夹**：扇区越大，占用的空间越多。单击文件夹进入，单击中间区域返回上一级。
3. **放进清理篮**：按住扇区并拖到左下角。放进清理篮不会立即删除文件。
4. **检查后永久删除**：确认名称、位置和大小都正确，再继续。

完整扫描结果会在本机保留 7 天，返回清理页面时不需要立刻重新扫描。进入某个文件夹时，StatusOrbit 会检查当前这一层并更新扇形图。如果其他位置发生了较多变化，请选择“重新扫描”。

#### 删除前务必知道

- 文件不会进入系统废纸篓，删除后无法通过 StatusOrbit 恢复。
- 建议先清理可以重新生成的缓存。下载内容、项目文件、设置和个人资料不确定时不要删除。
- StatusOrbit 只处理你个人文件夹内的普通文件和文件夹。
- 主目录、废纸篓本身、链接、特殊文件和其他磁盘不会被删除。
- 真正删除前，应用会再次检查文件是否发生变化。发现不一致时会停止操作。
- 删除成功的项目会立即从扇形图和清理篮中消失；失败的项目会保留下来并说明原因。

### 网络

- 查看当前上传和下载速度、本次启动后的累计流量、网络接口和活动连接。
- 可以按 TCP、UDP 和连接状态筛选列表。
- 系统不一定允许普通应用读取每条连接属于哪个进程，所以没有显示应用名并不代表连接有问题。

### 启动项

- 查看哪些应用会随电脑启动，以及它们来自哪里。
- 支持的第三方项目可以关闭，也可以稍后恢复。
- 系统项目和当前平台无法安全修改的项目只供查看。
- StatusOrbit 不会直接删除启动项的配置文件。

### 历史

- 历史页按时间保存 CPU、内存、磁盘和网络的整体变化，让你回看电脑什么时候开始变忙、什么时候恢复正常。
- 记录可以保留 1、7 或 30 天，也可以关闭或随时清空。
- 只有问题持续一段时间时才会提醒，同一问题不会反复弹出。
- CPU、内存和磁盘提醒可以分别关闭。
- 不保存命令行、文件路径、文件名或连接地址。

### 设置

- 更改语言、系统采样速度、活动连接刷新速度、颜色提示和默认的应用列表样式。
- 选择历史记录保留时间，并分别开关 CPU、内存和磁盘桌面提醒。
- 更短的刷新间隔响应更快，也会增加少量系统开销。

## 状态栏面板

关闭主窗口后，StatusOrbit 仍会留在状态栏。点开状态栏图标，可以快速查看 CPU、内存、磁盘和网络状态，也可以重新打开主窗口。

如果要完全停止监控，请退出 StatusOrbit，而不是只关闭窗口。

## 常见问题

### 刚启动时为什么没有网络或磁盘速度？

应用需要先后读取两次数据才能算出速度。等到下一次刷新就会显示。

### 为什么扫描要等很久？

扫描时间主要取决于文件数量和磁盘速度，而不是磁盘总容量。大量小文件通常比少量大文件更慢。页面会持续更新进度，你也可以主动停止。

### 为什么大小和 Finder 或 Explorer 显示的不一样？

StatusOrbit 显示文件实际占用的磁盘空间。压缩文件、稀疏文件和硬链接等情况，可能会让这个数字与文件标称大小不同。

### 为什么有些连接没有应用名？

操作系统可能不允许普通应用读取连接属于哪个进程。StatusOrbit 不会为了补全这项信息自动申请更高权限。

## 隐私与问题反馈

监控、文件、进程、历史和连接信息只保存在这台电脑上，不会上传或同步。扫描只读取名称、大小、位置等文件信息，不读取文件内容。

普通问题可以在 GitHub Issues 中反馈。请写清楚操作系统、刚才做了什么，以及看到的错误信息。安全问题请使用 GitHub 的私密漏洞报告功能。
