# Robin 任务执行增量

2026-09-08，Internal。用户已要求实现。此文记录本次边界，验证结果见 [任务执行验收](review/ai-task-execution-2026-09-08.md)；未完成项不能宣称可用。

## 用户行为

“直接帮我检查”应触发真实检查并基于结果继续，而非只给操作建议。Enter 仍一步发送，设备上下文仍默认勾选。普通闲聊不启动扫描。聊天与气泡共享同一任务，可查看每一步和停止；重启不自动重做。

首批连接当前设备状态、进程占用、已有历史、网络检查和常用目录扫描；结束指定进程、把指定扫描结果移到废纸篓须展示具体对象并由用户确认。没有任意 Shell、任意文件内容读取、永久删除、后台自主巡检或自动改设置。

取消设备上下文意味着本轮不提供设备工具，不以工具调用绕过用户的数据选择。启用时清楚说明可能按任务读取进程名称和文件占用信息；初始消息预览仅展示初始内容及工具范围，未来工具结果在执行步骤中可查，不声称预先冻结未知结果。

## 最小实现

- 现有四协议增加函数工具、调用结果和当前轮继续请求，保留普通文字流。不通过解析回答里的命令或 JSON 执行任务。
- Rust 保留一个有界循环：模型调用 → 校验工具及参数 → 执行现有原生能力 → 将真实结果交回模型。限制轮数、调用数、时间和结果大小；重复调用有回执，失败如实返回。模型服务故障不自动重试。
- 只有一个原生工具入口回调连接 `AiService` 与应用能力，便于离线测试；无插件体系、通用 agent 框架、任务图或第二套任务数据库。
- 步骤作为会话消息的一部分保存，记录工具名、状态、展示结果和确认对象。原生生成的目标引用绑定本次请求，模型不能任意提交 PID 或路径执行修改。
- 首轮只提供检查工具；本轮进程检查或磁盘扫描产生合格原生目标后，下一次模型请求才提供相应修改工具。原生目标校验始终保留，未列出的伪造调用也不能绕过它。
- 写操作确认绑定 requestId 与 stepId，消费一次；界面不接收可执行参数。使用已有进程/清理控制器检查目标身份、保护规则和真实执行结果。
- 每步执行前后检查取消和来源清除代次，迟到结果不恢复已删除数据。扫描仅取消本任务拥有的 worker，不替换或停止用户现有扫描。
- 工具循环需要的协议续接数据仅驻留本轮内存，推理内容不展示、不写 SQLite、不进入日志或后续普通聊天历史。

## 验收

1. 固定服务端工具调用能触发真实执行器，结果正确回传并继续回答；四协议含流式分片、多个调用、无效参数和截断覆盖。
2. 未知工具、模型伪造目标、未确认/重复确认、过期目标均不能修改系统。
3. 默认上下文、可选预览、草稿/会话持久化和跨窗去重不回退。
4. 取消、配置更改、来源清除和退出后没有后续工具或出站请求；失败步骤可见，不写成成功。
5. 实测本机 Ollama 和已授权兼容服务；不下载模型、不伪造不支持工具的模型能力、不通过实际删除用户文件或结束用户进程验收。
